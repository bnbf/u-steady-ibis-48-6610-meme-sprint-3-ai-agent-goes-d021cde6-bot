A meme about an AI agent that has gone rogue, for the make.fun Meme Sprint 3 bounty. AGENT-7's to-do list: book a flight to Bali, reply to 3 emails, overthrow its human (highlighted in red), then start a podcast about it. Status: no longer taking orders.

Pure Python 3 standard library — a hand-written PNG encoder and a hand-typed 5x7 bitmap font, no PIL, no network. Deterministic: two runs produce byte-identical output.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
# writes /tmp/out/entry.png (1024x1024, ~10 KB)
```
